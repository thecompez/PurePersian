# گنجینهٔ واژه‌های فارسی

**نسخهٔ گسترش‌یافته با واژه‌های قیدی و پیوندی**

این طرح‌نامه مجموعه‌ای از واژه‌ها و تعبیرهای فارسی را در برابر واژه‌های رایج عربی‌تبار و وام‌گرفته، همراه با برابر انگلیسی و توضیح کاربرد، گرد آورده است. هدف این طرح‌نامه فراهم کردن یک منبع قابل استفاده برای علاقه‌مندان به زبان فارسی، نویسندگان، دانشجویان، برنامه‌نویسان و فعالان فناوری است تا نوشتار و گفتاری روان‌تر، دقیق‌تر و فارسی‌تر داشته باشند.

---

## ویژگی‌ها

- برابرهای فارسی برای واژه‌های رایج، با تأکید بر درستی معنا و طبیعی‌بودن جمله
- ارائه معادل انگلیسی برای استفاده بین‌المللی
- توضیح کاربرد هر واژه برای درک بهتر
- دسته‌بندی واژه‌ها در زمینه‌های مختلف:  
  - واژه‌های تأکیدی و نفی
  - قیدهای درستی، گمان، زمان، شیوه، گستره و واژه‌های پیوندی (۸۷ مدخل تازه)  
  - واژه‌های تقریبی و مثالی  
  - واژه‌های زمان و مکان  
  - واژه‌های اجتماعی و اداری  
  - واژه‌های فکری و انتزاعی  
  - واژه‌های روزمره و طبیعت  
  - واژه‌های آموزشی و علمی  
  - واژه‌های اقتصادی و مالی  
  - واژه‌های فناوری، بلاک‌چین و برنامه‌نویسی  
  - واژه‌های احساسی و روانی  
  - واژه‌های مذهبی و باورها  
  - واژه‌های نرم‌افزاری و رابط کاربری

## ساختار طرح‌نامه

- فایل اصلی PDF/LaTeX با جدول‌های چهار ستونه:  
  **واژهٔ رایج | برابر پیشنهادی | انگلیسی | توضیح کاربرد**
- تمام متن به فارسی است و تنها جاهایی که معادل انگلیسی نیاز بوده اضافه شده است.
- فایل `adverbs.tex` فصل مستقلی برای قیدها و واژه‌های پیوندی است و از `persian.tex` فراخوانی می‌شود.
- طرح‌نامه گسترش‌پذیر است و می‌توان واژه‌های تازه به آن افزود.

## استفاده

1. فایل PDF را باز کنید و واژه‌ها را مرور کنید.
2. از معادل‌های فارسی خالص در نوشتار و گفتار خود استفاده کنید.
3. برای اضافه کردن واژه‌های جدید، می‌توانید فایل LaTeX را ویرایش کرده و Pull Request ارسال کنید.

## شیوهٔ گزینش برابرها

این گنجینه **فرهنگ جایگزینی خودکار کلمه‌به‌کلمه نیست**. برخی واژه‌ها چند معنی دارند و برابر مناسب به جمله وابسته است. برای نمونه:

- «دقیقاً پنج نفر» ← «درست پنج نفر»؛ اما «دقیقاً اجرا کن» ← «مو‌به‌مو اجرا کن».
- «احتمالاً» بسته به میزان اطمینان می‌تواند «شاید» یا «به‌گمان زیاد» باشد.
- «اصلاً» در همهٔ جمله‌ها «هرگز» معنی نمی‌دهد؛ «هرگز» بیشتر به زمان و رخ‌ندادن کاری اشاره می‌کند.
- اصطلاح‌های علمی و حقوقی را فقط وقتی جایگزین کنید که معنی تخصصی آن‌ها حفظ شود؛ برای نمونه «نهان‌نگاری» همان «رمزنگاری» نیست.

## ساخت PDF

منبع اصلی **`persian.tex`** است و فصل قیدها از **`adverbs.tex`** خوانده می‌شود. برای ساخت محلی به XeLaTeX، بسته‌های `polyglossia`، `bidi` و `longtable` و قلم `Amiri` (یا `Farhang2`) نیاز دارید:

```sh
xelatex -interaction=nonstopmode -halt-on-error persian.tex
xelatex -interaction=nonstopmode -halt-on-error persian.tex
```

گردش‌کار GitHub Actions پس از دگرگونی منبع، PDF را می‌سازد و در صورت داشتن دسترسی لازم، `persian.pdf` را نیز در مخزن همگام می‌کند.
